# Построение графа по его представлениям

Консольная программа на Python. Строит граф по одному из четырёх представлений и переводит его в остальные три:

- список рёбер;
- матрица смежности;
- список смежности;
- матрица инцидентности.

Поддерживаются ориентированные и неориентированные графы, взвешенные и невзвешенные. Также можно задать петли, кратные рёбра и изолированные вершины. Вершины называются числами или словами. Граф можно нарисовать (networkx + matplotlib) и сохранить в любом представлении.

## Установка

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt
```

## Запуск

### Лаунчер для Windows

Двойной щелчок по `run.bat` в корне папки открывает интерактивное меню. Аргументы передаются в `main.py`: `run.bat -i examples\edge_list.txt -f edges -w`. Если папки `.venv` нет, лаунчер сам создаст её и установит зависимости из `requirements.txt`.

### Интерактивное меню

```bash
python main.py
```

```
=== Построение графа ===

Текущий граф: граф ещё не задан
  1. Ввести граф с клавиатуры
  2. Загрузить граф из файла
  3. Показать все представления
  4. Показать одно представление
  5. Нарисовать граф
  6. Сохранить представление в файл
  7. Сохранить рисунок в файл (PNG)
  0. Выход
```

Сначала нужно выбрать формат ввода и ответить, ориентированный ли граф и взвешенный ли он. Затем данные вводятся с клавиатуры (пустая строка завершает ввод) или берутся из файла. После загрузки программа сразу показывает все четыре представления.

### Режим командной строки

```bash
# все представления взвешенного неориентированного графа из списка рёбер
python main.py -i examples/edge_list.txt -f edges -w

# только матрица инцидентности ориентированного графа, заданного матрицей смежности
python main.py -i examples/adjacency_matrix.txt -f adjmatrix -d -s incidence

# перевести список смежности в матрицу смежности и сохранить в файл
python main.py -i examples/adjacency_list.txt -f adjlist -d -w -c adjmatrix -o matrix.txt

# нарисовать граф в окне / сохранить рисунок
python main.py -i examples/incidence_matrix.txt -f incidence --draw
python main.py -i examples/incidence_matrix.txt -f incidence -s none --png graph.png --layout circular

# граф из стандартного ввода
printf "1 2\n2 3\n" | python main.py -i - -f edges
```

| Параметр | Значение |
|---|---|
| `-i ФАЙЛ` | входной файл (`-` — стандартный ввод) |
| `-f` | формат входа: `edges`, `adjmatrix`, `adjlist`, `incidence` |
| `-d` | ориентированный граф |
| `-w` | взвешенный граф |
| `-s` | что показать: `all` (по умолчанию), `none` или один из форматов |
| `-c ФОРМАТ -o ФАЙЛ` | сохранить граф в указанном формате |
| `--draw` | открыть окно с рисунком |
| `--png ФАЙЛ` | сохранить рисунок (подходят и `.svg`, `.pdf`) |
| `--layout` | раскладка вершин: `spring`, `circular`, `shell`, `spectral` |

## Форматы ввода

Общие правила:

- `#` начинает комментарий;
- пустые строки пропускаются;
- элементы разделяются пробелами, запятыми или `;`;
- дробные числа пишутся через точку: `2.5`.

Имя вершины из одних цифр считается числом. В именах нельзя использовать пробелы и символы `# : ( ) , ;`, а также называть вершину знаком стрелки (`-`, `->`, `—`, `→`). Вместо пробела можно писать `_`, например `Сергиев_Посад`.

Строка `V: a b c` необязательна. Она задаёт имена и порядок вершин. Для матриц без неё вершины называются `1..n`. В списке рёбер с её помощью добавляют изолированные вершины.

### Список рёбер — `edges`

```
V: A B C D      # необязательно; D — изолированная вершина
A B 4           # ребро A–B с весом 4 (у невзвешенного графа просто «A B»)
B C 2
A -> C 7        # между вершинами можно писать -, ->, — или →
```

### Матрица смежности — `adjmatrix`

```
V: A B C        # необязательно
0 4 7
4 0 2
7 2 0
```

- `0` означает, что ребра нет.
- В невзвешенном графе элемент равен числу рёбер между вершинами, так задаются кратные рёбра.
- Во взвешенном графе элемент — это вес ребра.
- Петля записывается на диагонали.
- У неориентированного графа матрица должна быть симметричной.
- В ориентированном графе строка — начало дуги, столбец — её конец.

### Список смежности — `adjlist`

```
A: B(4) C(7)    # во взвешенном графе вес в скобках; в невзвешенном — «A: B C»
B: A(4) C(2)
C: A(7) B(2)
D:              # вершина без соседей
```

У каждой вершины должна быть своя строка. В неориентированном графе ребро записывается у обоих концов, а петля — один раз.

### Матрица инцидентности — `incidence`

Строки соответствуют вершинам, столбцы — рёбрам.

```
V: A B C        # необязательно
1 1 0           # e1 = A–B, e2 = A–C, e3 = B–C
1 0 1
0 1 1
W: 4 7 2        # только для взвешенного графа: веса рёбер по столбцам
```

- Неориентированный граф: в столбце две единицы, петля обозначается одной двойкой.
- Ориентированный граф: `-1` стоит у начала дуги, `1` у конца, петля обозначается одной двойкой.

## Проверка ввода

Программа не строит граф по некорректным данным. Вместо этого она объясняет, что не так, и по возможности указывает номер строки:

```
Ошибка: матрица смежности несимметрична: [1][2] = 1, а [2][1] = 0. У неориентированного графа она должна быть симметричной
Ошибка: строка 3: в строке 2 элементов, а в первой строке матрицы (строка 1) — 3
Ошибка: столбец e2: ожидалось две единицы или одна двойка (петля), найдено — 1: 1, 2: 1, 3: 1
Ошибка: строка 1: сосед 5 вершины 1 — несуществующая вершина: добавьте строку «5:» (можно с пустым списком)
Ошибка: ребро 1–2 указано в списке вершины 1 1 раз(а), а в списке вершины 2 — 0. ...
```

Во взвешенной матрице смежности нельзя записать кратные рёбра и ребро с весом 0, потому что 0 там означает «ребра нет». Для такого графа программа покажет причину вместо матрицы. Остальные три представления при этом работают.

## Примеры

В папке `examples/` по одному файлу на каждый формат. В начале каждого файла есть комментарий с командой запуска.

| Файл | Граф |
|---|---|
| `edge_list.txt` | неориентированный взвешенный: дороги между городами, одна изолированная вершина |
| `adjacency_matrix.txt` | ориентированный невзвешенный: встречные дуги, кратная дуга, петля |
| `adjacency_list.txt` | ориентированный взвешенный: сеть доставки |
| `incidence_matrix.txt` | неориентированный невзвешенный: кратные рёбра и петля |

## Структура

```
graph.py        класс Graph: хранение, from_* / to_* для четырёх представлений, проверки
parsers.py      разбор текста и файлов в Graph
formatters.py   вывод на экран (таблицы) и запись в текстовый формат
visualize.py    отрисовка (networkx + matplotlib)
main.py         интерактивное меню и командная строка
examples/       примеры входных файлов
tests/          тесты pytest
```

### Использование из Python

```python
from graph import Graph

g = Graph.from_adjacency_matrix([[0, 1], [1, 0]], vertices=["a", "b"])
g.to_edge_list()          # [('a', 'b')]
g.to_adjacency_list()     # {'a': ['b'], 'b': ['a']}
g.to_incidence_matrix()   # [[1], [1]]

d = Graph.from_incidence_matrix([[-1], [1]], weights=[5], directed=True)
d.to_adjacency_matrix()   # [[0, 5], [0, 0]]
```

## Тесты

```bash
python -m pytest
```

Главная проверка: если перевести граф из представления A в B и обратно в A, получается исходный граф. Она выполняется для всех 16 пар форматов на графах разных типов: с петлями, кратными рёбрами, изолированными вершинами и строковыми именами. Каждую пару проверяют дважды: через Python API и через запись в текст с последующим разбором. Отдельные тесты покрывают проверку ввода, вывод таблиц, отрисовку и консольный интерфейс.
